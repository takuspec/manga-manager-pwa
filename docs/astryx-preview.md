# Astryx比較試作

起動: `npm run dev -- --port 5176` → `/manga-manager-pwa/astryx-preview.html`。
独立ビルド: `npm run build:preview`（出力: dist-preview）。本番エントリーとPWAには混ぜない。

Astryx 0.7.13のButton・TextInput・Badge・Themeとneutralテーマを使用。ページ構成・余白・配色・レスポンシブ配置はこのアプリ用に設計したもので、Astryxを導入するだけで自動的にこの外観になるわけではない。

読む／雑誌／完結／年表／設定の5画面。検索、未読絞り込み、誌別一覧、作品詳細、色モードを操作できる。端末の既存データを読み取り、データがなければ架空のサンプルを表示。作品詳細の増分は画面内だけの操作実験で、正式な号送り・保存・編集の実装ではない。年表は開始イベントの閲覧用試作。合併号、バックアップ、画像保存処理は既存のまま。

今回の比較対象は情報設計・見た目・操作感。正式導入には全編集機能との接続、全年刊行ルール、アクセシビリティとキーボード操作の包括検証、CSS/JSサイズの最適化が必要。

検証: 本番と試作のビルド、試作コードのLint、390px幅の横はみ出しと表紙寸法、検索、作品詳細とEscape、雑誌切り替え、ライト／ダーク表示。
