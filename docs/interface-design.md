# 画面デザインの更新

## 基本方針

既存の漫画管理データと画像を使い、ネイビーの背景、青い選択色、細い境界線で画面を統一する。雑誌・作品の表紙寸法は従来のまま。画像の再登録や再トリミングは不要。

- 雑誌一覧：誌名と未読合計を強調し、右上のオプションとアイコン付き下部ナビゲーションを配置。
- 作品一覧：作者、読了号、未読数、集計対象外バッジを整理。並び替えは独立したボタンで開閉。
- 作品メニュー：下部のモーダルシート。外側、閉じるボタン、Escapeで閉じる。削除を赤色で分離。
- 編集：既存の入力・保存処理を維持。作品編集と雑誌編集の保存をヘッダーへ移動。
- 完結・年表：リスト表示を初期表示にし、グリッドにも切り替えられる。作者別画面も同じ配色へ。
- 未読・完結フィルター：選択中は青い背景と枠、非選択はグレー。ON/OFFの文字は付けない。

## 合併号設定

生成画像にあった固定の号ペア一覧は採用しない。既存の年度別設定で、合併にする号とその隣の号を順に選択する方式を維持する。年度ごとに異なる組み合わせを登録できる。全年度52号・53号の一括変更と全連載+1/-1は復活させない。

## 互換性

App.cssの画像寸法、ImageView、IndexedDB、localStorageの保存キー、バックアップ・インポート処理、読了数計算は変更しない。生成画像の架空の表紙はアプリに追加しない。

320・390・430px幅で従来CSSと更新CSSを比較し、雑誌一覧、作品一覧、完結一覧、編集、年表、グリッドの画像寸法が一致することを確認する。

## 表紙の代表寸法

| 表示箇所 | 幅×高さ |
|---|---|
| 雑誌一覧 | 72×100px |
| 完結・年表の雑誌選択 | 72×92px |
| 作品リスト・作者別 | 92×124px |
| 編集 | 120×170px |
| 年表リスト | 64×86px |
| グリッド | 既存の画面幅・倍率に連動する寸法を維持 |
